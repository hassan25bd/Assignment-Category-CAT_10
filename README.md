# PetNest Server

Backend API for PetNest Pet Adoption Platform.

## Tech
- Node.js
- Express
- MongoDB
- JWT in HTTPOnly cookies

## Run
1. `npm install`
2. Create `.env` from `.env.example`
3. `npm run dev`

## Important Environment Variables
- `MONGODB_URI`
- `JWT_SECRET`
- `CLIENT_URL`
- `NODE_ENV`
